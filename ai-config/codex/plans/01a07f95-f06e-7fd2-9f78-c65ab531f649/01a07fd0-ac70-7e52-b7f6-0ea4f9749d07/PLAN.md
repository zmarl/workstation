
# 投資の方法論を深め、更新し続けるフレームワークの構成・改訂計画

## 1. 設計方針

**投資機会の発見から、企業理解、判断、資金配分、保有管理、振り返りまでを体系的に言語化する。**

「なぜ投資するのか」「人生にとって投資とは何か」は構成に含めない。心理や思考の癖は、判断や行動に影響した具体的な場面で扱う。

文書は、本人が項目ごとに読み返せ、AIも必要な箇所を特定して更新できる構成にする。現在の考え方を本文にまとめ、その理由・具体例・例外・未解決の問いを近くに置く。

既存文章は改訂材料として使う。以前から書かれていることだけを理由に、本人の方法論として残さない。これまでの採用済みの議論と後発訂正を土台にする。

## 2. 中心となる五つの領域

| 領域 | 中心となる問い | 掘り下げる項目 |
|---|---|---|
| **① 市場と投資機会の捉え方** | どこに機会があり、何に気づけば見つけられるか | 市場評価と実態の差、情報・解釈・時間軸の違い、投資家の期待、マクロ・業種・需給、構造変化と循環、候補の探し方 |
| **② 企業と価値の理解** | 何を理解し、何を基準に企業を評価するか | 事業構造、競争、経営、売上・利益、財務、資産・負債、資金創出、追加投資、資本政策、評価方法、同業比較 |
| **③ 投資判断の組み立て** | なぜ今の情報と価格で投資する・待つ・見送るのか | 仮説と因果、支持・反証、織り込み、条件別評価、上値・下値、時間軸、カタリスト、情報不足、個別手法の使い分け |
| **④ 資金配分と保有中の判断** | どれだけ持ち、何を待ち、何が変われば対応するか | 機会比較、サイズ、集中、流動性、レバレッジ、テール、追加・縮小・退出、入替、再エントリー、売買コスト |
| **⑤ 振り返りと方法論の更新** | 判断のどこを改善し、何を維持するか | 判断と結果の分離、成功・失敗・見送り、原因の切り分け、判断時の心理、成績評価、手法の適用限界、新しい考えの検討と改訂 |

この五つを全体目次の主構成にする。既存の戦略IDやフォルダを一括して置き換える分類にはしない。

個別の投資手法は③から辿れるようにし、企業理解やリスク管理の共通部分は②・④を参照する。決算分析・利益モデルは②・③の一部として位置づけ、他の評価経路も同じように詳しく扱う。

## 3. 五つの領域に補う観点

五つの大分類だけでは埋もれやすい以下の観点を、独立した項目として配置する。これは文書の検討対象を定めるもので、具体的な判断ルールの採用ではない。

| 補う観点 | 何を言語化するか | 主な配置先 |
|---|---|---|
| **情報収集と調査の方法** | 何を知るために何を読むか。一次情報、比較、情報の新しさ、矛盾、追加調査の優先順位、調査を終える条件 | ①・③ |
| **市場参加者と価格形成** | 誰が何を評価し、どのような情報・資金移動・制約によって評価が変わると考えるか | ① |
| **時間と変化の順序** | 事業の変化、業績への反映、開示、市場の認識、株価反応がどの順に起こるか。何が先行指標になり、何を待つか | ①・③ |
| **利益から株主価値への接続** | 利益が現金や株主価値につながる過程。設備投資・運転資金・負債・希薄化・還元などをどう評価するか | ② |
| **複数要因の相互作用** | 業績・倍率・需給が同時に動く場合、要因が逆方向に動く場合、同じ効果を二重に評価している場合の考え方 | ②・③ |
| **不確実性の扱い** | 事実、計算、仮定、因果の推論をどう分けるか。数字にできない情報、未知、反証にどう対応するか | ③ |
| **機会費用と何もしない判断** | 現在の保有、別の候補、現金で待つことをどう比較するか。資金拘束と調査に使う時間をどう考えるか | ③・④ |
| **売買の実行と価格差** | 分析上の魅力が、実際に買える・売れる条件やコストによってどう変わるか | ④ |
| **手法が通用する条件と限界** | どの企業・相場・時間軸で使えるか。うまくいった例の共通点と、通用しなかった理由 | ③・⑤ |

心理は「自分はどんな人か」という独立した章にせず、「買値への固執で再評価が遅れた」「見逃した焦りで条件を緩めた」など、方法論を改善できる形で⑤に置く。

既存の情報鮮度・事業理解・実行品質・見送り検証の文書は材料として利用する。ただし、そこにある自動減点、固定期限、勝率変換などを、そのまま新しい本文へ引き継がない。

## 4. 文書の形と継続更新

### 項目ごとの本文

一つの文書は一つの中心的な問いに答え、以下を基本形にする。

- **何を考える項目か**
- **現在の考え方・判断方法**
- **そう考える理由と仕組み**
- **具体的な適用例**
- **例外・反例・使えない条件**
- **自問すること・まだ解けていない問い**
- **関連項目と、採用・変更の根拠**

毎項目に形式だけの空欄を設けない。短く説明できるものは短く、複雑なものは必要な深さまで書く。用語の定義、注意点、適用範囲を散在させず、同じ箇所で理解できるようにする。

### 全体の読み方

- **全体目次**：五つの領域と、各項目で答える問いを示す。
- **現在の本文**：本人が今使う考え方を説明する。
- **事例・参考資料**：実際の判断、反例、計算例、一般理論を参照する。
- **日々の記録・変更履歴**：気づき、原発言、旧来の考え、変更理由を保存する。

人間用とAI用に本文を二重管理しない。見出しとリンクで必要な範囲を読めるようにし、AIが毎回全資料を読み込む前提にはしない。

### 更新の流れ

**日々の発言・気づき → 関連項目の特定 → 現在の考えとの比較 → 本文の更新または問いとして保存 → 変更理由を残す**

- 本人が明確に述べた考えの変更は反映する。
- 迷い、検討中の手法、AIによる新しい解釈は、採用済みの本文と読み分けられる形で残す。
- 一つの経験から一般化できる範囲が不明なら、その部分だけ確認する。
- 更新回数・取引件数・経過月数を、文書の訂正や考えの言語化の一律条件にしない。
- 手法の効果を確かめるときは、その問いに合う比較・検証方法を定める。
- 過去の判断は当時の前提とともに保持し、新しい考えによる再評価を追加する。

ユーザーに毎回フォームの入力を求めず、自由な対話からAIが関連項目と更新内容を整理する。更新手順と記録先は既存のレビュー・変更管理へ統合し、新しい常設台帳を増やさない。

## 5. 改訂の進め方と完成条件

### 実施順序

1. **五領域と追加観点の詳細目次を作る**  
   既存文書と採用済みの議論を対応づけ、「既に言語化されている」「整理が必要」「内容が不足している」を作業記録上で整理する。個別項目への長い質問を始める前に、全体の抜けを見えるようにする。

2. **合意済みの内容から全体を組み立てる**  
   Q1〜Q127、後発訂正、今回の構成・更新方針を既存本文へ反映する。本人の考えとして確認できない部分は創作せず、参考・提案・問いとして残す。未決の全解決を待たず、五領域を一通り読める状態にする。

3. **項目間の意味を揃える**  
   評価、時間軸、上値・下値、反証、サイズ、出口、振り返りを横断確認する。本文を直しても旧テンプレートから別の判断が入り込まないよう、関連する説明と記録項目も更新する。

4. **読み返しと更新を実例で確かめる**  
   業績中心、資産・財務中心、イベント中心の例に、見送り・失敗・再エントリーを混ぜる。方法論の不足と、単に記述が分かりにくい箇所を分けて修正する。

5. **検証して正式文書へ統合する**  
   参照リンク、既存metadata、文書を読む処理への影響、採用内容の対応漏れを確認し、合意済みの通常手順でmainへ統合する。そこで見えた未解決の問いを、次の深掘り対象にする。

### アプリとの境界

今回の対象は文書体系と関連設計までとし、公開API・DB・計算処理・画面の変更は行わない。既存の文書読取処理が依存するパス・見出し・表を確認し、一括移動や無確認の構造変更を避ける。

後続のアプリは、項目別の閲覧、気づきと本文の接続、当時の方法論に基づく判断の振り返りを支える。文書への採用とアプリへの実装状態を分け、未反映の差を明示する。

### 完成条件

- 投資の動機・人生観を説明する章がなく、方法論に内容が集中している。
- 五つの領域と追加観点から、必要な項目へ迷わず辿れる。
- 各項目で現在の考え、理由、使い方、限界、未解決の問いが分かる。
- AIが関連する正本を特定し、本人の意思と提案を混同せず更新できる。
- 日々の気づきが記録だけに埋もれず、関係する本文へ戻る。
- 採用済み事項が反映され、旧規則・参考知識・現行実装との差を読み分けられる。
- 新しい手法や考えを加えても、過去の判断理由と変更経緯を失わない。

最初の成果は、**現在の投資方法論の全体を読み返せ、足りない問いが見え、そこから継続して掘り下げられる正式な文書体系**とする。
