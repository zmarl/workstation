# マクロ画面全面刷新 — 半導体サイクル縦断版

## 要約

- `/macro` を既存4タブへの継ぎ足しではなく、「マクロ統計・先行指標」として置き換える。
- 検討した3案から、次の構成を採用する。
  1. 更新された統計と変化を確認する入口
  2. 数値を読める長期チャート
  3. 統計→業種→企業KPI→決算をたどる詳細
- 初回は半導体サイクルに限定し、以下を公式データから収録する。
  - [TSMC月次売上](https://investor.tsmc.com/english/monthly-revenue/2026)：絶対額、前月比、前年比
  - [韓国産業通商資源部の月次輸出資料](https://www.motir.go.kr/kor/article/ATCL3f49a5a8c/172077/view)：半導体輸出額、前年比
  - [鉱工業指数](https://www.meti.go.jp/statistics/tyo/iip/index.html)：製造工業全体・生産用機械の生産、出荷、在庫、在庫率
- 旧韓国税関の「1〜20日輸出入総額」は半導体指標ではなく取得停止済みのため、初回データには使用しない。

## 実装内容

### 画面構成

- 上部には「直近に公表・改定された統計」と具体的な変化だけをコンパクトに表示する。月次統計を日次データへ補間しない。
- 中央をチャートの主領域とし、右側に以下を表示する。
  - この統計が表すもの
  - 何の先行・関連指標か
  - 影響経路と想定ラグ
  - 同時期の出来事
  - 次に確認する企業KPI・決算
- TSMCは売上額の棒グラフと前年比の同期折れ線、韓国半導体輸出も絶対額と前年比を分離表示する。
- IIPは生産・出荷・在庫・在庫率を同一軸へ重ねず、同期した4つのスモールマルチプルで表示する。
- 期間選択は `1か月 / 3か月 / 6か月 / 1年 / 3年 / 5年 / 10年 / 全期間`。月次系列の既定は10年、データ点は月次のまま保持する。
- 全チャートで次を必須にする。
  - 実際の観測日を使ったX軸
  - 数値目盛と単位を持つY軸
  - 最新値、比較値、カーソル位置の正確な値
  - 欠測期間と基準年変更
  - 公表日、改定状態、出所
  - 下部の実数値テーブル
- 短期・中期・長期を不透明なスコアにせず、前月比、前年比、3か月・12か月移動平均、連続上昇・低下月数、10年レンジ内の位置で説明する。

### 意味と企業への接続

- 「先行指標」と呼べるのは、先行対象、影響の仕組み、想定ラグ、過去検証が揃う系列だけとする。それ以外は「関連指標」「候補」と明示する。
- 影響経路は `統計 → 需要・価格・在庫・設備投資 → 業種 → 企業KPI → 決算` で表示する。
- 企業は汎用的な上位銘柄を並べず、既存の業種・サブセクター・企業KPI対応に根拠がある場合だけ接続する。
- 関係状態は `確認済み / 候補 / 未確認` に限定する。
- 出来事は公式発表、決算、設備投資・生産計画など出所を持つ事実を表示する。因果が証明されていないものは「同時期の出来事」「原因候補」とし、LLMに原因を断定させない。

### 旧表示の整理

- 旧4タブ、技術的な書き込み先表示、環境総合スコア、レジーム点数、ナラティブクラスター、テーマランウェイ、季節性・アノマリー、根拠不足のVIX/HYスプレッド等を `/macro` から外す。
- 為替、指数価格、海外投資家フローは重複表示しない。既存の専用画面を正本とする。
- 市場の広がりとセクターローテーションは、対象市場・除外条件・セクター寄与を直した後にセクター画面で扱う。本変更では壊れた表示を移設しない。
- 価格チャートは初回対象外。将来追加する場合は線グラフではなくローソク足を必須とする。
- 旧APIとバックエンド処理はロールバック用に残すが、新しい `/macro` からは参照しない。削除は利用確認後の別作業とする。

## API・データ契約

- Desktopは引き続きFastAPI BFFだけを使用する。
- 公開契約を次の2本に集約する。
  - `GET /api/v1/macro/statistics-context?focus=semiconductor&as_of=...`
    - 更新一覧、系列グループ、最新値、変化、データ品質、影響経路を返す。
  - `GET /api/v1/macro/series/{series_key}/context?range=...&compare=...`
    - 履歴、変換値、出来事、欠測、出所、企業・決算接続を返す。比較系列は最大4本。
- 主な型は `MacroSeriesMetadata`、`MacroObservation`、`MacroEventAnnotation`、`MacroImpactPath`、`MacroDataQuality` とする。
- 観測値には観測日と公表日を分けて保持し、最新改定値と当時入手可能値を区別する。過去時点値を復元できない系列は、PIT対応済みと偽らない。
- 新規DDLは行わず、既存のraw/core統計格納先とIIP格納先を再利用する。
- TSMC・韓国半導体輸出は直近10年を必須範囲として履歴補完し、それ以前は公式に取得できる範囲を全期間表示する。
- IIPは2020年基準系列を正本とし、長期接続系列を使う区間には基準変更点と比較上の注意を表示する。

## 検証・反映

- 取得処理では公式資料のfixtureを使い、絶対額、前年比、月、単位、改定、重複月、欠測を検証する。
- BFF契約テストで、日付順、単位、期間抽出、4系列比較、部分欠測、古いデータ、出所、確認状態を証明する。
- Desktopテストで、軸・目盛・ツールチップ・実数値表・期間切替・基準変更・出来事・企業リンク・空表示を検証する。
- 実画面は1440×900と375×812で確認し、横スクロール、過大な空白、読めない軸、情報の分断がないことをスクリーンショットで証明する。
- 公式データのdry-runで対象期間、予定件数、欠測、更新差分を記録する。想定件数と一致した場合だけ、承認済み範囲としてローカルPostgreSQLへトランザクション内で履歴補完する。不一致なら書き込まず停止する。
- 履歴補完後、実BFF・実DBで `/macro` を開き、3データ群の実数値、10年表示、出所、企業KPI・決算導線を確認する。
- 外部worktreeとworklogを起こし、本計画を根拠にマクロ画面の目的をODRへ記録する。focused検証、1回の独立レビュー、最終SHAのReady gateを通して統合する。
- Scheduler登録、共有・本番DBへの反映、Desktop配布は今回の承認範囲外とする。

## 完了条件

- `/macro` を開いた直後に、少なくともTSMC・韓国半導体輸出・IIPの意味のある実データが読める。
- 各系列について「何の数値か」「どう変わったか」「どの期間の変化か」「何へ影響し得るか」「次に何を確認するか」が一画面で分かる。
- 軸や単位のないチャート、不明なスコア、根拠のないナラティブ、技術的な保存先表示が主画面に残っていない。
- 欠測・古いデータ・未確認の関係は、正常値や確認済み分析として表示されない。
- 実データ反映後の画面確認と最終ゲートが成功するまで「使える状態として完了」としない。
