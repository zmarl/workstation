# Investment UI の表示密度とアプリ反映

- Investment の画面変更では、画面幅を埋めるためだけにカード、表、カレンダーを横へ引き伸ばさない。
- 情報量を落とさず、内容に合う最大幅と「左の主情報 + 右の補助情報」を基本にし、狭い画面では縦積みにする。
- 通常幅だけでなく、ユーザー環境の 3440px 超横長画面でも、左端の開始位置、右側だけの余白、横スクロールの有無を実アプリで確認する。
- アプリ向け変更は、明示的に除外されない限り、main へ統合後にローカル release アプリを再ビルド・再起動し、タスクバーから開く実アプリへ反映して確認可能な状態まで進める。
