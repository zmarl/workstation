# セクターページ可視化フィードバック (2026-07-19 初回利用)

ユーザー評価: 6 セクション構成は意図どおり見えている。ただし可視化 2 点が分かりにくい。

- **ヒートマップ**: タイル面積の意味が不明（実装は銘柄数だった）。「時価総額で大きさを分類できているのか」
  → **面積は時価総額が直感**。全体の大きさ・表示方法も要見直し（→全幅化+キャプション明記で対応）
- **RRG ローテーション**: 「意味がよくわからない。点が何を表しているのかも不明」
  → 点=業種の可視ラベル表示 + 折りたたみの「この図の見方」平易解説を標準に

**Why**: ユーザーは非技術者。チャートの慣習（treemap の面積・RRG の象限）は前提知識にできない。
**How to apply**: 新しい可視化を出すときは①エンコーディングの意味（面積=何/色=何）をキャプションで常時明記
②専門図（RRG/散布図等）には日本語の「この図の見方」開示を必ず併設 ③面積・サイズ系は時価総額など
金額基準を既定にする。関連: [[project-desktop-design-reform-2026-07-19]]
